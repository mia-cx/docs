# Code style preferences

- **Early returns**
- **`const` arrow functions** — `const toggle = () => {}` over `function`. Define types.
- **Tailwind** — Limit `<style>` blocks or inline CSS.
- **a11y** — Interactive elements need `tabindex`, `aria-label`, keyboard handlers.
- **DRY** — Repeated patterns? Abstract them.
- **File naming** — kebab-case for all files and directories.
- **Colors** — OKLCH color space for design tokens (e.g., `oklch(0.141 0.005 285.823)`).
